# Aplikasi Komite Keperawatan

Aplikasi berbasis web untuk mendukung pengelolaan data dan dokumen Komite Keperawatan.

## Teknologi

- Laravel
- PHP
- MySQL/MariaDB
- Blade, CSS, dan JavaScript
- Node.js dan NPM

## Fitur

- Login aplikasi
- Dashboard
- Pengelolaan data personal
- Pengelolaan panduan
- Pengelolaan sertifikat
- Pengelolaan Standar Prosedur Operasional (SPO) Keperawatan
- Pengelolaan data Komite Keperawatan

## Persyaratan

Pastikan perangkat telah memiliki:

- PHP sesuai persyaratan Laravel
- Composer
- MySQL atau MariaDB
- Node.js dan NPM
- Git
